# Noob 骨折模拟器 · Break Lab v4.9

游戏地址：https://stone2013.github.io/roblox-noob-r6/?v=4.9.0

## v4.9 新增
- 物理 2.0：17 次位置约束迭代、加强角阻尼与碰撞稳定性。
- 可破坏建筑：木屋墙壁和屋顶带实体碰撞，高速撞击会碎裂；碎片限量并自动回收。
- 载具系统：生成物理矿车，靠近后乘坐；WASD 或手机摇杆驾驶，跳跃可弹射。
- 雪山增强：山体增加多组倾斜岩壁和雪面碰撞体，形成更多不规则山脊。
- 回放系统：自动记录摔落关键帧，结束后可点击“🎬 回放”观看慢动作。

保留四张地图、六块积木 Noob、骨折计分、可破坏树木、商店积分和永久解锁、第一/第三人称、力气/布娃娃模式以及 PWA 离线缓存。

## 操作
WASD 移动/驾驶；Shift 奔跑；空格跳跃或从矿车弹射；R 切换力气；C 切换视角；F 开始摔落。手机使用横屏摇杆、跳跃和底部按钮。

## 技术边界
项目使用自带 WebGL/Canvas 渲染器与自定义位置约束刚体引擎，不依赖第三方 CDN。雪山是低模倾斜碰撞块拼接，并非真正的三角网格高度场。回放仅记录 Noob 六块刚体姿态，暂不回放建筑碎片或载具轨迹。

已做源码一致性与导入路径检查；仍需浏览器、手机触控、PWA 离线和完整关卡实机回归测试。
