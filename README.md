# Noob 骨折模拟器 · Break Lab v4.9.3

游戏地址：https://stone2013.github.io/roblox-noob-r6/?v=4.9.3

## v4.9 新增
- 物理 2.0：17 次位置约束迭代、加强角阻尼与碰撞稳定性。
- 可破坏建筑：木屋墙壁和屋顶带实体碰撞，高速撞击会碎裂；碎片限量并自动回收。
- 载具系统：生成物理矿车，靠近后乘坐；WASD 或手机摇杆驾驶，跳跃可弹射。
- 连续雪山：以低模三角网格构成多峰山脊、鞍部、峡谷、陡坡、悬崖和雪区；人物移动、布娃娃、矿车、道具放置与渲染共用同一高度场。
- 回放系统：自动记录摔落关键帧，结束后可点击“🎬 回放”观看慢动作。

保留四张地图、六块积木 Noob、骨折计分、可破坏树木、商店积分和永久解锁、第一/第三人称、力气/布娃娃模式以及 PWA 离线缓存。

## 操作
WASD 移动/驾驶；Shift 奔跑；空格跳跃或从矿车弹射；R 切换力气；C 切换视角；F 开始摔落。手机使用横屏摇杆、跳跃和底部按钮。

## 技术边界
项目使用自带 WebGL/Canvas 渲染器与自定义位置约束刚体引擎，不依赖第三方 CDN。雪山使用单张共享三角网格高度场，约 2,800 个三角面；自研物理引擎以网格三角面的高度和法线解析动态刚体接触。回放仅记录 Noob 六块刚体姿态，暂不回放建筑碎片或载具轨迹。

自动化地形回归：运行 node --test tests/mountain.test.mjs，覆盖网格/碰撞表面一致性、边界与山峰采样、行走落地与跳跃、六块布娃娃翻滚、矿车尺寸刚体及高处坠落。部署完成后仍需真实手机横屏、触控和 PWA 离线测试。
