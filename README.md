# Noob 骨折模拟器 · Break Lab 4.0

六块积木，一场重力实验。由原 Noob R6 PWA 改造的非血腥卡通物理游戏；非 Roblox 官方产品，骨折点是游戏计分，不是医学模拟。

## 游玩

https://stone2013.github.io/roblox-noob-r6/?v=4.0.0

选择赛道，点击「开始摔落」，根据碰撞产生伤害与得分，停稳后结算。治疗或重试可回到起点。

- 16 米高台、20 级阶梯、24 米山谷滑坡。
- 六个受伤区域，共 48 个虚拟骨折点；裂纹、受伤示意、得分反馈和本地纪录。
- 六块刚体、五个受限关节；力气 / 布娃娃、第一 / 第三人称、行走、跳跃及慢动作。
- 五种道具保留：炸弹、弹簧、木箱、球、气球。使用道具或拖拽后不计入挑战纪录。
- 新积木山谷、树木、云、护栏、凸点底板、光影与横屏界面。

## 操作

电脑：WASD 移动，Shift 奔跑，空格跳跃，F 开始摔落，R 切换力气，C 切换视角。空白处拖动转镜头，滚轮缩放。

手机：左下摇杆移动，空白处滑动转镜头，右下按钮跳跃或摔落。建议横屏。力气关闭后可拖动身体。

## 运行与 PWA

无需构建、无需 npm、没有外部 CDN。将本目录放到静态 HTTPS 站点即可。模块版需通过 HTTP/HTTPS 打开，不建议直接双击 index.html。

本地开发可运行 `python -m http.server 8000` 后访问 localhost:8000。PWA 首次在线安装完成后缓存本站游戏文件。更新使用独立版本缓存，只清理 noob-r6- 前缀的旧缓存，不删除同域其他项目的缓存。

保留原应用 id 和 Pages 地址。已安装用户可先在线打开带 v=4.0.0 的网址，再重新启动主屏幕图标。

## 测试与边界

实际通过 Chromium 浏览器的 26 项检查，包括三赛道摔落结算、六刚体五关节、站立脚底、行走与跳跃、第一人称隐藏头部及表情、844×390 横屏多点触控、治疗复位、气球升起、炸弹触发布娃娃和静止不刷分。三赛道测试均有得分并停稳结算，未发现 JavaScript 运行错误。

测试环境禁用了 WebGL，实际检查运行的是内置软件三维兼容渲染路径。硬件 WebGL 阴影路径、iPhone Safari 真机和 PWA 离线安装更新尚未完成实机验收。物理是为卡通玩法调校的位置约束求解器，不是高精度工程仿真；角色部件之间关闭自碰撞以提高稳定性。

原 PWA 已保存在分支 `backup/pwa-before-break-lab-v4`。
